**Astro** is a web framework for building content-driven websites (e.g.
Documentation sites, blogs, portfolios...). It can be used to statically
generate sites from markdown files. It's similar to
existing static site generators like Jekyll (Ruby) or Hugo (Go).

*NOTE*: It's **not** a web framework for SPAs!

## Highlights

- **Islands**. Component-based web architecture.
- **UI-agnostic**. Supports React, Vue, Svelte...
- **Server-first**. SSR as default with selective CSR.
- **Zero JS by Default**. Less JS overhead.
- **Content collections**. Create typesafe collections using TS and MD.
- **Customizable**.

## Design Principles

- **Content-driven**. Astro was designed to showcase your content.
- **Server-first**. Websites run faster when they render HTML on the server.
- **Fast by default**. It should be impossible to build a slow website in Astro.
- **Easy to use**. You don’t need to be an expert to build something with Astro.
- **Developer-focused**. You should have the resources you need to be successful.
